A wildlife early-warning prototype designed to detect possible elephant sightings with YOLO, notify a team, and optionally signal an Arduino indicator — while keeping the AI and hardware on the monitoring computer.

View project code ↗How the system works
AI DETECTOR
YOLO + OpenCV
Runs locally against a camera feed. The hosted webpage does not run this Python process.
HARDWARE
Arduino Nano
Optional USB serial output from the monitoring computer; this website cannot access the USB port.
NOTIFICATIONS
ntfy alerts
The desktop prototype can send a possible-sighting notification when configured and running.

Run the actual detector

STEP 01

Prepare the computer

Use Windows with Python installed. Connect the webcam and, if using it, the Arduino Nano.
STEP 02

Install dependencies

Open a terminal in the downloaded repository and run:
py -m pip install ultralytics opencv-python pyserial
STEP 03

Start local monitoring

Run py gajaguard_app.py. Check the camera, COM port, and notification topic in the desktop app.
Prototype safety note: This hosted page is a project dashboard, not a live detection feed. No camera, AI, Arduino, or sighting status is connected to this page yet. Treat AI detections as unverified and do not use this prototype as the sole basis for field-safety decisions.
